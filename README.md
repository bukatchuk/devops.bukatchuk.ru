# devops.bukatchuk.ru

Лендинг курса «База, которую не придётся доучивать» — путь в DevOps для тех, кто уже работает в ИТ.
Статический сайт на Jekyll, публикуется на GitHub Pages.

## Как править содержимое

Весь текст лежит в `_data/` — по файлу на блок страницы. Разметку трогать не нужно: правите YAML, коммитите, сайт пересобирается сам.

Порядок блоков задаётся в `index.html` — одна строка на блок, менять местами можно перетаскиванием строк.

### Что важно знать про поля

- Поля с окончанием `_html` (`title_html`, `html`) допускают теги: `<br>` для переноса строки, `<a href="…">` для ссылки, `<strong>` для выделения. Остальные поля — простой текст.
- В ленте показателей `fill` — ширина оранжевой полоски под цифрой, в процентах.
- В карточках программы `variant` управляет цветом: пусто — белая, `dark` — чёрная, `safety` — оранжевая. `wide: true` растягивает карточку на две колонки.
- В тарифах `highlight: true` подсвечивает целевой тариф оранжевой тенью, `no: true` у пункта списка делает его перечёркнутым.

### Что подставить перед запуском продаж

Плейсхолдеры в квадратных скобках подсвечены оранжевым прямо на странице:

- ссылки оплаты — `_data/hero.yml`, `_data/price.yml`, `_data/tariffs.yml`, `_data/cta.yml`;
- ссылка на публичное оглавление курса — `_data/program.yml`;
- реквизиты ИП — `_data/footer.yml`;
- данные в оферте и политике — `offer.md` и `privacy.md`: ФИО, ИНН, ОГРНИП, расчётный счёт, почта, название платёжного сервиса, сроки возврата и дата редакции.

**Оферта и политика — черновики.** Структура и формулировки соответствуют тому, что обещано на странице курса, но перед публикацией их нужно показать юристу и заполнить всё, что стоит в квадратных скобках. Отдельно проверьте пункт 4.3 политики: он честно говорит, что шрифты загружаются с серверов Google и туда уходит IP посетителя. Если это неприемлемо — шрифты можно положить в репозиторий, тогда сторонних запросов у сайта не останется вовсе.

## Как устроен репозиторий

```
_config.yml              настройки Jekyll
index.html               порядок блоков главной страницы
offer.md                 публичная оферта, /offer/
privacy.md               политика обработки персональных данных, /privacy/
_layouts/default.html    каркас: head, шапка, подвал, подключение стилей
_layouts/page.html       каркас текстовых страниц: оферта и политика
_includes/header.html    шапка
_includes/footer.html    подвал
_includes/sections/      по файлу на блок — разметка, данные подставляются из _data
_data/                   тексты и числа
assets/css/main.css      стили (собраны из макета, порядок правил сохранён)
assets/js/main.js        часы, бургер-меню, появление блоков при прокрутке
assets/img/              логотип и favicon
CNAME                    devops.bukatchuk.ru
```

## Локальный просмотр

```bash
bundle install
bundle exec jekyll serve
# http://127.0.0.1:4000
```

## Публикация

Пуш в `main` запускает `.github/workflows/jekyll-gh-pages.yml`: сборка через `actions/jekyll-build-pages` и публикация через `actions/deploy-pages`. В настройках репозитория **Settings → Pages → Source** должно стоять **GitHub Actions**.

Ветки и пул-реквесты проверяются отдельным workflow `.github/workflows/checks.yml`: он собирает сайт без публикации, проверяет наличие `index.html`, стилей и `CNAME` и печатает список оставшихся плейсхолдеров.

## Откуда взялся дизайн

Макет собран в репозитории курса (`products/landings/kurs-devops.html`) по мотивам шаблона Axis Industrial. Структура страницы — пятнадцать блоков продающей упаковки. При правках стоит держаться правил: три карточки в ряд, единый вертикальный ритм секций, текст на всю ширину блока, подписи-номера словами и прописными.
